1. Technology and Production

Technology, input choices, and returns to scale.

Technology and production

Vocabulary

Production function

A production function measures the maximum output, denoted by $y$, that can be obtained from a given input vector $z$. It describes the technological relation between the inputs used by a producer and the output that can be produced.

Production function and utility function. The production function $f$ plays a role similar to a utility function in the sense that it maps a vector into a number. The difference is that production functions are cardinal, whereas utility functions are ordinal.

Throughout this chapter, the production function is assumed to satisfy the following properties.

Essentiality

$$f(0)=0.$$

With no inputs, the maximum output is zero.

Smoothness

The production function is twice continuously differentiable, so its first and second derivatives can be used in the analysis.

Monotonicity

Increasing the amount of at least one input produces at least as much output as before. More input does not reduce the maximum feasible output.

Production set and isoquant

Production set

The production set $I^0$ contains all input bundles that can produce at least the output level $y^0$:

$$I^0=\{z\mid f(z)\geq y^0\}.\tag{1}$$

It is analogous to a feasible set.

Isoquant curve

The isoquant $Q^0$ contains all input bundles that produce exactly the output level $y^0$:

$$Q^0=\{z\mid f(z)=y^0\}.\tag{2}$$

It is analogous to an indifference curve.

Convexity of the production set

The production set $I^0$ is convex. If $z^a$ and $z^b$ are two ways of producing $y^0$, any mixture of these two input bundles can produce at least as much output. The isoquant curves form the boundary of the production set.

How to read the figure

The input bundles $z^a$ and $z^b$ lie on the same isoquant, so each produces the same output. The mixture $z^c$ lies inside the production set associated with that output level.

The figure therefore shows the meaning of convexity: combining two feasible input plans remains feasible for producing at least the same output.

Time horizon

Short- and Long-Term

Consider a production function with two inputs. Input $z_1$ is a variable input: its quantity can be varied instantaneously. Input $z_2$ is a fixed input: its quantity can be varied from period $t$ to period $t+1$.

Short term — period 0

The producer can vary $z_1$ while $z_2$ remains fixed.

Long term — period 1

The producer can vary both $z_1$ and $z_2$.

Two responses

Input substitution changes one input while the others are constant. Returns to scale vary all inputs in the same proportion.

Focus of the course. Input substitution is typically studied in the short term. Returns to scale are typically studied in the long term.
Short-term properties

Marginal Product

The marginal product of input 1 measures the change in output when input 1 changes while input 2 is held fixed:

$$MP_1=\frac{\partial y}{\partial z_1}=f'(z_1).\tag{3}$$
Reading the assumption. At least one input has a positive marginal product: this is the productivity assumption. Marginal product is typically assumed to be diminishing. Output still rises when more of input 1 is used, but it rises at a decreasing rate.

Marginal Rate of Technical Substitution

The marginal rate of technical substitution measures the change in input 2 needed to keep output constant when input 1 changes:

$$MRTS_{12}=\frac{MP_1(z_1,z_2)}{MP_2(z_1,z_2)}=-\frac{dz_2}{dz_1}.\tag{4}$$

The MRTS is the technical counterpart of the marginal rate of substitution. It is usually assumed to be diminishing.

Graphical meaning. The MRTS is minus the slope of an isoquant. When the MRTS is diminishing, the slope, which is minus the MRTS, changes so that isoquants are convex.
Do not confuse the two assumptions. A diminishing $MRTS_{12}$ concerns how the ratio of marginal products changes when $z_1$ rises and $z_2$ falls along the same isoquant. A diminishing $MP_1$ concerns how $MP_1$ changes when $z_1$ rises while $z_2$ is held fixed.

Elasticity of Substitution

The elasticity of substitution connects changes in the input ratio to changes in the MRTS:

$$\sigma=\frac{\%\text{ change in }z_2/z_1}{\%\text{ change in }MRTS_{12}} =\frac{d\ln(z_2/z_1)}{d\ln MRTS_{12}}.\tag{5}$$

It measures the percentage change in the ratio $z_2/z_1$ associated with a 1% change in the MRTS between the two inputs. A higher elasticity means that the firm can substitute one input for the other more easily.

Moving from point $A$ to point $B$ on a given isoquant, both the MRTS and the input ratio change. The elasticity of substitution is the ratio of these changes, so it measures the curvature of the isoquant.

Low elasticity

Large changes in the MRTS are associated with small changes in the input ratio. The inputs are poor substitutes; the isoquant is approximately flat.

High elasticity

Small changes in the MRTS are associated with large changes in the input ratio. The inputs are easily substitutable.

Long-term properties

Returns to Scale

Returns to scale measure the change in output when both inputs are multiplied by the same factor $s$. They can be characterized by the degree of homogeneity $\nu$ of the production function or by the elasticity of scale $E$.

$$E=\frac{\partial f(s\cdot z)/f(s\cdot z)}{\partial s/s} =\frac{\partial f(s\cdot z)}{\partial s}\frac{s}{f(s\cdot z)}.\tag{6}$$

The elasticity of scale compares the change in output caused by scaling all inputs with the common proportional change in inputs.

Constant returns

$$s\cdot f(z_1,z_2)=f(sz_1,sz_2).\tag{7}$$

Here $E=1$, or $f$ is homogeneous of degree $\nu=1$.

Increasing returns

$$s\cdot f(z_1,z_2)<f(sz_1,sz_2).\tag{8}$$

Here $E>1$, or $f$ is homogeneous of degree $\nu>1$.

Decreasing returns

$$s\cdot f(z_1,z_2)>f(sz_1,sz_2).\tag{9}$$

Here $E<1$, or $f$ is homogeneous of degree $\nu<1$.

Homogeneous functions of degree $\nu$

When the production function is homogeneous of degree $\nu$, scaling every input by $s$ gives $f(sz)=s^\nu f(z)$. The elasticity of scale is then equal to the degree of homogeneity:

Elasticity of scale

$$\begin{aligned} E&=\frac{\partial f(s\cdot z)}{\partial s}\frac{s}{f(s\cdot z)}\\ &=\frac{\partial\left[s^\nu f(z)\right]}{\partial s}\frac{s}{s^\nu f(z)}\\ &=\left[\nu s^{\nu-1}f(z)\right]\frac{s}{s^\nu f(z)}\\ &=\nu. \end{aligned}\tag{10}$$

The first equality is the definition of $E$. The next line uses homogeneity, and differentiating $s^\nu f(z)$ gives the final result.

Its partial derivatives are homogeneous of degree $\nu-1$:

$$f_i'(sz)=s^{\nu-1}f_i'(z).\tag{11}$$

Therefore, the slope of an isoquant depends on input proportions $z_i/z_j$, rather than the scale of production:

$$\begin{aligned} MRTS_{ij}(sz)&=\frac{f_i'(sz)}{f_j'(sz)}\\ &=\frac{s^{\nu-1}f_i'(z)}{s^{\nu-1}f_j'(z)}\\ &=\frac{f_i'(z)}{f_j'(z)}. \end{aligned}$$

How to read the figure

The bundles $(z_1,z_2)$ and $(sz_1,sz_2)$ lie on the same ray from the origin: their input proportions are the same.

The tangents have the same slope, illustrating that the MRTS depends on the input proportions and not on the production scale.

Industry patterns discussed in class. Tobacco and food can display decreasing returns because fragile materials create spoilage and quality-control constraints. Paper, petroleum, and metal can display increasing returns because they require large capital investment at the outset, such as refineries or steel mills.

Incorporating increasing or decreasing returns to scale

Starting from a function $f$ with constant returns to scale, the course considers the transformation:

$$F(z_1,z_2)=\left[f(z_1,z_2)\right]^\gamma, \qquad\gamma>0.$$

Effect of the transformation

$$\begin{aligned} F(sz_1,sz_2)&=\left[f(sz_1,sz_2)\right]^\gamma\\ &=\left[s f(z_1,z_2)\right]^\gamma \qquad\text{by CRS of }f\\ &=s^\gamma\left[f(z_1,z_2)\right]^\gamma\\ &=s^\gamma F(z_1,z_2). \end{aligned}\tag{12}$$

If $\gamma>1$, $F$ exhibits increasing returns to scale. If $\gamma<1$, $F$ exhibits decreasing returns to scale.

Returns to scale over the growth of a firm

As a firm grows, it can successively experience increasing, constant, and decreasing returns to scale.

The figure marks an input level $z^A$ and the corresponding output $y^A$ on the production function.

Research focus

Research Focus: IT, Robots and Cloud Technologies

This research focus studies the consequences of declines in IT prices, cloud-services adoption, and robot adoption for firms.

Falling IT prices

Lashkari, Bauer, & Boussard (2024), Information technology and returns to scale.

Context and questions

IT prices have declined substantially over recent decades. The study asks how these declines affect returns to scale at the firm level, firms’ concentration, and the labor share.

Data and method

Firm-level data from France, 1989–2007. The analysis estimates firm-level elasticity of IT demand.

Two possible effects

  • Substitution effect: firms substitute IT for other inputs as IT becomes cheaper.
  • Returns-to-scale effect: as output grows, demand for IT rises more than proportionally; cheaper IT can therefore generate increasing returns to scale.

Results

  • IT demand is scale-dependent. Larger firms invest more in IT per employee: doubling firm size is associated with a 30–50% increase in IT investment per employee.
  • Returns to scale. Larger firms have higher IT-demand elasticity as output increases. IT-price declines lead to increasing returns to scale for larger firms.
  • Concentration and labor share. IT-price declines raise profit shares at IT-intensive firms because of higher returns to scale. They contribute to concentration in production at larger, more IT-intensive firms. IT-intensive firms reduce labor’s share of income, contributing to an aggregate decline in labor share.

Policy implications

Larger, IT-heavy firms benefit most from lower IT prices, which increases productivity disparities. Smaller firms may need policy support to adopt IT and remain competitive.

Cloud services’ adoption

Context and questions

Cloud computing transforms traditional IT infrastructure into a pay-on-demand service. The study asks how cloud adoption affects firm growth and performance, and how it changes the geographical distribution of firm activities.

Data

Firm-level data on more than 15,000 UK firms, 2013–2015.

Methods

  • Fiber broadband speeds are used as an instrument for cloud adoption.
  • A difference-in-difference approach compares firms according to proximity to fiber-enabled broadband; firms closer to it are more likely to adopt cloud computing.

Results

  • Firm performance. Young firms, under 10 years old, experience significant annual increases in employment (+14.3%) and sales (+15.9%). Incumbent firms, over 10 years old, show no significant effect on employment or sales. Productivity gains are higher for younger firms.
  • Geographical distribution. Employees work further away from headquarters. There is less geographical dispersion: younger firms are less likely to become multi-centric, while incumbent firms are more likely to close some centers.

Implications

Cloud computing helps young firms grow in size and productivity, while incumbent firms focus on restructuring. Cloud technologies may reduce barriers for new entrants and level the playing field between small and large firms.

Robots’ adoption

Koch, Manuylov, & Smolka (2021), Robots and firms.

Context and questions

The study responds to concerns about robots replacing human labor. It asks which firm characteristics make robot adoption more likely and how adoption affects firm performance.

Data and method

Firm-level data on more than 5,500 firms in Spain, 1990–2016. The method combines difference-in-difference estimation with propensity-score matching.

Firms adopting robots

  • Larger, more productive firms and exporters are more likely to adopt robots.
  • Conditional on size, firms with higher skill intensity are less likely to adopt.

Impact on firm performance

  • Robot adoption raises output by 20–25% within four years.
  • Adopting firms experience a 10% increase in total employment, including low- and high-skilled jobs.
  • The labor-cost share falls by 5–7 percentage points after adoption.

Implications

Encouraging robot adoption may raise productivity, but it also requires attention to inequalities between adopting and non-adopting firms.

3 · Profit-maximization problem

The Profit Function

The profit function $\pi$ associates to a given output price $p$ the highest profit the producer can obtain: the largest difference between revenue and input costs.

$$\pi=\max_z\;p\cdot y-z\cdot w \qquad\text{s.t.}\qquad f(z)=y.\tag{1}$$

Here, $p$ is the output price and $w$ is the vector of input prices. The producer is assumed to be a price-taker: $p$ and $w$ are taken as given.

The Profit-Maximization Problem

Assume that $f$ is strictly quasi-concave and twice continuously differentiable. Replacing output $y$ by $f(z)$ gives the long-term profit-maximization problem:

$$\max_z\;p\cdot f(z)-z\cdot w.\tag{2}$$
Outputs of the problem. The unconditional input demand $z_\pi(w,p)$ is the solution to the profit-maximization problem. It is unconditional because the producer is not required to meet a fixed output target. The profit function $\pi$ is the value function of this problem.

First-order condition

Choose input $z_i$ until its value equals its cost

$$\begin{aligned} \frac{\partial\left[p\cdot f(z)-z\cdot w\right]}{\partial z_i}&=0\\ p\frac{\partial f(z)}{\partial z_i}-w_i&=0\\ p\cdot MP_i&=w_i. \end{aligned}\tag{3}$$

The value of the marginal product of input $i$ is $p\cdot MP_i$. At the optimum, it equals the price $w_i$ of that input.

If $p\cdot MP_i>w_i$

The input creates more revenue at the margin than it costs. Profit can be increased by using more of it.

At the optimum

The value of the marginal product equals the input price.

If $p\cdot MP_i<w_i$

The input costs more at the margin than the revenue it creates. Profit can be increased by using less of it.

4 · Cost-minimization problem

The Cost Function

The cost function associates to an output target $\bar y$ the minimum cost of producing it:

$$C(w,\bar y)=\min_z\;w\cdot z \qquad\text{s.t.}\qquad f(z)=\bar y.\tag{4}$$

It is the value function of the cost-minimization problem.

Properties of the cost function

If $f$ is continuous and strictly increasing in $z$, the cost function has the following properties.

At zero output

Cost is zero when $\bar y=0$.

Continuity

The cost function is continuous.

Monotonicity

Cost increases in $\bar y$ and is non-decreasing in $w$.

Homogeneity in $w$

It is homogeneous of degree 1 in $w$: if all input prices double, total cost doubles.

Concavity in $w$

Cost rises more slowly than input prices because the firm can substitute between inputs. The firm never pays more than the weighted average of the two costs.

Cost-Minimization Problem

Assume that $f$ is strictly quasi-concave and twice continuously differentiable. The long-term cost-minimization problem is:

$$\min_z\;w\cdot z \qquad\text{s.t.}\qquad f(z)\geq\bar y.\tag{5}$$
Conditional input demand. The conditional input demand $z_C(w,\bar y)$ is the solution. It is conditional because the firm chooses its inputs subject to reaching the given output level $\bar y$. The cost function $C(w,\bar y)$ is the value function of this problem.

Properties of conditional input demand

Prices scaled together

If $f$ is quasi-concave and twice continuously differentiable, $z_C(w,\bar y)$ is homogeneous of degree 0 in $w$. Scaling all input prices by the same factor changes total cost but not the relative input quantities.

Under constant returns to scale

$$C(w,\lambda\bar y)=\lambda C(w,\bar y),$$
$$z_C(w,\lambda\bar y)=\lambda z_C(w,\bar y).$$

Producing $\lambda$ times more output requires exactly $\lambda$ times each input, and total cost rises proportionally.

Solving graphically

Choose the lowest isocost for the target isoquant

Isoquant curves show combinations of inputs producing the same output. Isocost lines show combinations of inputs with the same total cost.

For a given output level, the cost-minimizing bundle is the point $z^*$ on the relevant isoquant that lies on the lowest achievable isocost line.

The isocost lines are parallel straight lines because input prices are independent of the quantity of the inputs. An isocost line is defined by:

$$w_1z_1+w_2z_2=C, \qquad\text{hence}\qquad z_2=\frac{C}{w_2}-\frac{w_1}{w_2}\cdot z_1.$$

Tangency condition

Solving the cost-minimization problem means finding the lowest-cost input bundle for a given isoquant. At $z^*$, the slopes are equal:

$$\text{slope isocost}=\text{slope isoquant}.$$
$$-\frac{w_1}{w_2}=-\frac{MP_1}{MP_2},$$
$$\frac{w_1}{MP_1}=\frac{w_2}{MP_2}.\tag{6}$$

Solving with a Lagrangian

As for the consumer’s UMP, the producer’s cost-minimization problem can be written with a Lagrangian:

$$L=w\cdot z+\lambda[\bar y-f(z)].\tag{7}$$

By the Envelope Theorem, the derivative of the value function with respect to a parameter equals the derivative of the Lagrangian with respect to that parameter. Here:

$$\lambda=\frac{\partial C(w,\bar y)}{\partial\bar y}.$$

The multiplier $\lambda$ is the rate at which minimum cost increases when the required output $\bar y$ increases.

Link between PMP and CmP

From PMP

The profit-maximization problem gives unconditional input demand $z_\pi(w,p)$. It therefore gives the supply correspondence $y(p,w)=f(z_\pi)$.

Every profit-maximizing input bundle is cost-minimizing for the output it produces.

From CmP

The cost-minimization problem gives conditional input demand $z_C(w,\bar y)$ for a fixed output level.

A cost-minimizing input choice for some output need not maximize profit, unless that output is the profit-maximizing level.

Course note. This distinction is related to technological and economic efficiency, studied below.

The profit-maximization problem can also be written using the cost function:

$$\max_y\;p\cdot y-C(w,y).$$

The supply correspondence $y(p,w)$ solves this problem. It is the output level at which the profit-maximizing input demand corresponds to the conditional cost-minimizing input demand. This formulation is useful when the cost function is known but the production function is not.

Expansion Path

The expansion path is the locus of cost-minimizing input combinations as output varies. A positive slope means that an increase in output raises both inputs.

Question raised in class. An expansion path can have a negative slope over part of its range when $z_1$ is an inferior input. In the second figure, output rises from $Q^A$ to $Q^B$ while the cost-minimizing quantity of $z_1$ falls.
Short-term cost function

Short-Term Properties of the Cost Function

Preamble

Average cost and marginal cost are defined by:

$$AC=\frac{TC(y)}{y}, \qquad MC=\frac{dTC(y)}{dy}.$$

Total cost differs between the short and long term. Consequently, average and marginal costs differ as well.

Short-term total and marginal cost

In the short run, $z_1$ is variable and $\bar z_2$ is fixed. Total cost is:

$$TC(y)=VC(z_1)+FC(\bar z_2).\tag{8}$$

Average cost can therefore be written as:

$$AC(y)=\frac{VC}{y}+\frac{FC}{y}.$$
Typical U-shape of marginal cost. Initially, $MC$ decreases because fixed inputs, such as machines or ovens, are underutilized: each additional unit costs less than the previous one. Eventually, $MC$ increases because fixed inputs become constraints: each additional unit costs more than the previous one.

Marginal cost and marginal product

$$\begin{aligned} MC(y)&=\frac{dTC}{dy}\\ dy\times MC(y)&=dTC\\ dy\times MC(y)&=dVC \qquad\text{because this is the short term}\\ dy\times MC(y)&=dz_1\times w_1\\ MC(y)&=\frac{dz_1}{dy}\times w_1\\ MC(y)&=\frac{w_1}{MP(z_1)}. \end{aligned}\tag{9}$$

Since $w_1$ is given, the marginal cost of producing one more unit of output depends only on the marginal productivity of $z_1$.

Zero-Profit and Shutdown Points

In the short term, the firm prefers to produce no output when its revenues do not cover variable costs. Producing a positive output requires:

$$p\cdot y>VC(y) \qquad\Longleftrightarrow\qquad p>\frac{VC(y)}{y}=AVC.$$

The boundary is the shutdown point. If fixed costs are positive, the firm can still produce an output $y>0$ even when profit is negative. The firm begins making profit when:

$$p>AC.$$

The corresponding boundary is the zero-profit point.

Read the two points

The shutdown point $S$ is at the minimum of $AVC_{ST}$, at price $p^s$.

The zero-profit point $ZP$ is at the minimum of $AC_{ST}$, at price $p^{zp}$.

Links between $mC$, $AC$, and $AVC$

Why $mC$ cuts averages at their minima

When $mC<AC$, the average is pulled down. When $mC>AC$, the average is pulled up. Thus the $mC$ curve cuts the average curves at their minimum points.

Why $AC$ tends to $AVC$

The gap between average cost and average variable cost becomes smaller as output grows.

Average fixed cost vanishes as output grows

$$\begin{aligned} TC(y)&=VC+FC\\ TC(y)&=w_1\cdot z_1(\bar z_2,y)+w_2\cdot\bar z_2\\ AC(y)&=\frac{w_1\cdot z_1(\bar z_2,y)}{y}+\frac{w_2\cdot\bar z_2}{y}. \end{aligned}$$

As $y$ tends to $+\infty$, average fixed cost tends to zero. Therefore, $AC$ tends to $AVC$.

Long-term cost function

Long-Term Properties of the Cost Function

In the long term, total cost is the cost function defined by the cost-minimization problem:

$$\begin{aligned} TC(y)&=\min_z\;w\cdot z &&\text{s.t.}\quad f(z)=\bar y,\\ TC(y)&=w\cdot z^*. \end{aligned}$$

Returns to Scale and Economies of Scale

Returns to scale describe the change in output when all inputs change in the same proportion. Economies or diseconomies of scale describe the change in total cost when output changes in this way.

$$E=\frac{\partial\ln(y)}{\partial\ln(s)}=\nu.$$

The elasticity of cost with respect to output is:

$$E^c=\frac{\partial\ln(C)}{\partial\ln(y)} =\frac{dC/C}{dy/y} =\frac{dC}{dy}\frac{y}{C} =\frac{MC}{AC}.$$

It answers: if output increases by 1%, by what percentage does total cost increase?

$E>1$		Economies of scale; marginal product increases; marginal cost decreases; $E^c<1$.$AC>MC$.

Why $AC>MC$ under economies of scale. A new unit costs less than the preceding units. It therefore costs less than the average unit, whose cost is the mean of old and new costs.

Long-Term Cost and Economies of Scale

Each $AC_{ST}$ curve corresponds to one plant size, or one level of fixed inputs. The long-term average-cost curve $AC_{LT}$ is the lower envelope of all these short-term average-cost curves. Because all inputs are variable in the long term, it gives the minimum average cost achievable at each output level when plant size and input combination can both be adjusted.

Under economies of scale, the long-term total-cost curve rises at a decreasing rate. Both $AC_{LT}$ and $mC_{LT}$ decrease, with $mC_{LT}<AC_{LT}$.

Long-Term Cost and Constant Returns to Scale

Under constant returns to scale, the minima of the short-term average-cost curves lie on a horizontal $AC_{LT}$. Long-term total cost is a straight line from the origin, and:

$$mC_{LT}=AC_{LT}.$$

Long-Term Cost and Diseconomies of Scale

Under diseconomies of scale, the lower envelope $AC_{LT}$ slopes upward. The long-term $TC_{LT}$, $AC_{LT}$, and $mC_{LT}$ curves increase, with marginal cost rising more steeply.

Question raised in class. Average costs can fall even without increasing returns to scale if prices are not exogenous. For example, bulk discounts can make input prices fall as purchase volume rises.

Back to the Profit Function

In the long term, there is no distinction between variable and fixed costs. The minimum of $AVC$ is therefore the same as the minimum of $AC$: the minimum of $AC$ corresponds to both the shutdown and zero-profit points.

Minimal optimal output

Meaning of $y_{\min}$

The minimal optimal output is the output level from which the firm no longer has economies of scale.

5 · Efficiency

Output and Technical Efficiency

Output efficiency

It is impossible to use the same input level to produce more output.

Technical efficiency

It is impossible to produce the same output level with fewer inputs.

Read the feasible points

$E^1$ is output inefficient: with the same input level, the firm can reach the output of $E^2$.

$E^3$ is technologically inefficient: it produces the same output as $E^2$ with more input.

Course note. It is often implicitly assumed that the firm is output efficient. The technological constraint is then written as binding: $y=f(z)$.

Relationship between the two concepts

$$\text{Technical efficiency}\Longleftrightarrow\text{Output efficiency}.$$

Technical efficiency implies output efficiency: if the firm uses the minimum inputs to produce a given output, it cannot use those same inputs to produce more.

Output efficiency implies technical efficiency: under monotonic production, if the firm produces the maximum output for given inputs, it cannot produce the same output with fewer inputs.

Economic Efficiency

Economic efficiency is achieved when it is impossible to produce the same output level at a lower cost. It differs from technical efficiency and output efficiency.

$$\text{Economic efficiency}\Longrightarrow\text{Technical efficiency} \Longleftrightarrow\text{Output efficiency}.$$

Why economic efficiency implies technical efficiency

If it is impossible to reduce cost, it is impossible to decrease the quantity of at least one input, because decreasing an input is the way to reduce cost. Thus it is impossible to decrease the total quantity of inputs.

Why technical efficiency need not imply economic efficiency

Technical efficiency prevents a reduction in the total quantity of inputs. It does not prevent changing the input ratio to reduce costs. A lower-cost combination can therefore still be possible.

Economic Efficiency and Welfare

Production side of the First Welfare Theorem

If a production vector $y\in Y$ is profit-maximizing for some price vector $p\gg0$, then it is economically efficient.

Proof. Suppose that $y$ is profit-maximizing:

$$p\cdot y\geq p\cdot y' \qquad\text{for all }y'\in Y.$$

Suppose by contradiction that $y$ is not efficient. Then there is $y'\in Y$ with $y'\geq y$ and $y'\neq y$. Since $p\gg0$, it follows that:

$$p\cdot y'>p\cdot y.$$

But this contradicts the profit-maximizing property of $y$.

Production side of the Second Welfare Theorem

If a production vector $y\in Y$, where $Y$ is a convex production set, is economically efficient, then it is profit-maximizing for some price vector:

$$p\geq0.$$
