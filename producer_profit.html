3. Profit-Maximization Problem

How the producer chooses inputs to maximize profit.

3 · Profit-maximization problem

The Profit Function

The profit function $\pi$ associates to a given output price $p$ the highest profit the producer can obtain: the largest difference between revenue and input costs.

$$\pi=\max_z\;p\cdot y-z\cdot w \qquad\text{s.t.}\qquad f(z)=y.\tag{1}$$

Here, $p$ is the output price and $w$ is the vector of input prices. The producer is assumed to be a price-taker: $p$ and $w$ are taken as given.

The Profit-Maximization Problem

Assume that $f$ is strictly quasi-concave and twice continuously differentiable. Replacing output $y$ by $f(z)$ gives the long-term profit-maximization problem:

$$\max_z\;p\cdot f(z)-z\cdot w.\tag{2}$$
Outputs of the problem. The unconditional input demand $z_\pi(w,p)$ is the solution to the profit-maximization problem. It is unconditional because the producer is not required to meet a fixed output target. The profit function $\pi$ is the value function of this problem.

First-order condition

Choose input $z_i$ until its value equals its cost

$$\begin{aligned} \frac{\partial\left[p\cdot f(z)-z\cdot w\right]}{\partial z_i}&=0\\ p\frac{\partial f(z)}{\partial z_i}-w_i&=0\\ p\cdot MP_i&=w_i. \end{aligned}\tag{3}$$

The value of the marginal product of input $i$ is $p\cdot MP_i$. At the optimum, it equals the price $w_i$ of that input.

If $p\cdot MP_i>w_i$

The input creates more revenue at the margin than it costs. Profit can be increased by using more of it.

At the optimum

The value of the marginal product equals the input price.

If $p\cdot MP_i<w_i$

The input costs more at the margin than the revenue it creates. Profit can be increased by using less of it.
