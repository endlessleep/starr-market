Exercise 1

Exercise 1. Cobb-Douglas and Returns to Scale

The Cobb-Douglas production function is given by:

$$f(z_1,z_2)=C\cdot z_1^\alpha\cdot z_2^\beta,\qquad C,\alpha,\beta>0.$$

For what positive values of $\alpha$ and $\beta$ is there …

  1. … decreasing returns to scale.
  2. … linear returns to scale.
  3. … increasing returns to scale.
  4. … decreasing marginal product for factor 1?

Questions 1–3 — Returns to scale

One common calculation

For all three questions, multiply both inputs by the same factor $s>1$:

$$\begin{aligned}f(sz_1,sz_2)&=C(sz_1)^\alpha(sz_2)^\beta\\&=C\,s^\alpha z_1^\alpha\,s^\beta z_2^\beta\\&=s^{\alpha+\beta}Cz_1^\alpha z_2^\beta\\&=\boxed{s^{\alpha+\beta}f(z_1,z_2).}\end{aligned}$$

Comparing this with $f(sz)=s^\nu f(z)$ shows that the degree of homogeneity is:

$$\boxed{\nu=\alpha+\beta.}$$

Compare with $s f(z_1,z_2)$

We have found $f(sz_1,sz_2)=s^{\alpha+\beta}f(z_1,z_2)$. Compare it directly with $s f(z_1,z_2)$:

$$\begin{aligned}\text{Decreasing returns:}\quad&s^{\alpha+\beta}f(z_1,z_2)<s f(z_1,z_2)\quad\Longleftrightarrow\quad\boxed{\alpha+\beta<1}\\\text{Linear / constant returns:}\quad&s^{\alpha+\beta}f(z_1,z_2)=s f(z_1,z_2)\quad\Longleftrightarrow\quad\boxed{\alpha+\beta=1}\\\text{Increasing returns:}\quad&s^{\alpha+\beta}f(z_1,z_2)>s f(z_1,z_2)\quad\Longleftrightarrow\quad\boxed{\alpha+\beta>1}\end{aligned}$$
Returns to scaleMeaning when inputs are multiplied by $s$
DecreasingOutput increases by less than $s$.
Linear / constantOutput increases by exactly $s$.
IncreasingOutput increases by more than $s$.

Question 4 — Decreasing marginal product for factor 1

Do not use the returns-to-scale calculation here. Questions 1–3 scale both inputs. Here, $z_1$ changes while $z_2$ is held fixed.

The marginal product of factor 1 is:

$$\begin{aligned}MP_1&=\frac{\partial f(z_1,z_2)}{\partial z_1}\\&=\frac{\partial}{\partial z_1}\left(Cz_1^\alpha z_2^\beta\right)\\&=\boxed{C\alpha z_1^{\alpha-1}z_2^\beta.}\end{aligned}$$

It is decreasing when its derivative with respect to $z_1$ is negative:

$$\frac{\partial MP_1}{\partial z_1}=\frac{\partial^2f(z_1,z_2)}{\partial z_1^2}=C\alpha(\alpha-1)z_1^{\alpha-2}z_2^\beta<0.$$

We know $C>0$, $\alpha>0$, $z_1^{\alpha-2}>0$, and $z_2^\beta>0$. The only factor determining the sign is $\alpha-1$.

$$\alpha-1<0\qquad\Longrightarrow\qquad\boxed{0<\alpha<1,\qquad\beta>0.}$$
PropertyCondition
Decreasing returns to scale$\alpha+\beta<1$
Linear / constant returns to scale$\alpha+\beta=1$
Increasing returns to scale$\alpha+\beta>1$
Decreasing marginal product of factor 1$0<\alpha<1$, with $\beta>0$
Exercise 2

Exercise 2. Elasticity of Substitution

Find the elasticity of substitution $\sigma$ of the following production functions.

  1. Cobb-Douglas:
    $$f(z_1,z_2)=z_1^\alpha z_2^\beta,\qquad\alpha,\beta>0.$$
  2. CES:
    $$f(z_1,z_2)=\left(z_1^\alpha+z_2^\alpha\right)^{1/\alpha},\qquad\alpha<1,\quad\alpha\neq0.$$

Question 1 — Cobb-Douglas

1. Marginal products

$$MP_1=\frac{\partial f}{\partial z_1}=\alpha z_1^{\alpha-1}z_2^\beta,\qquad MP_2=\frac{\partial f}{\partial z_2}=\beta z_1^\alpha z_2^{\beta-1}. $$

2. MRTS

Using the course definition $MRTS_{12}=MP_1/MP_2$:

$$\begin{aligned}MRTS_{12}&=\frac{\alpha z_1^{\alpha-1}z_2^\beta}{\beta z_1^\alpha z_2^{\beta-1}}\\&=\frac{\alpha}{\beta}z_1^{-1}z_2\\&=\boxed{\frac{\alpha}{\beta}\frac{z_2}{z_1}.}\end{aligned}$$

3. Take logarithms

$$\ln MRTS_{12}=\ln\left(\frac{\alpha}{\beta}\right)+\ln\left(\frac{z_2}{z_1}\right).$$

We differentiate both sides with respect to $z_2/z_1$. Recall that:

$$\frac{d\ln(x)}{dx}=\frac1x. $$

The first term disappears because $\alpha/\beta$ is constant:

$$\frac{d\ln MRTS_{12}}{d(z_2/z_1)}=0+\frac{1}{z_2/z_1}. $$
$$\boxed{\frac{d\ln MRTS_{12}}{d(z_2/z_1)}=\frac{1}{z_2/z_1}.}$$

Pass to differentials. Multiplying both sides by $d(z_2/z_1)$, we obtain:

$$d\ln MRTS_{12}=\frac{1}{z_2/z_1}d(z_2/z_1).$$

Since $d\ln(x)=\frac1x dx$:

$$\boxed{d\ln MRTS_{12}=d\ln\left(\frac{z_2}{z_1}\right).}$$

4. Elasticity of substitution

$$\sigma=\frac{d\ln(z_2/z_1)}{d\ln MRTS_{12}}=\boxed{1}. $$

Interpretation

Unit elasticity: along an isoquant, a 1% increase in MRTS is associated locally with a 1% increase in $z_2/z_1$.

Cobb-Douglas inputs are neither perfect substitutes nor perfect complements. Substitution is possible, but MRTS changes as the input ratio changes. Perfect substitutes have infinite substitution elasticity; perfect complements have zero substitution elasticity.

Question 2 — CES

Let $A=z_1^\alpha+z_2^\alpha$, so $f=A^{1/\alpha}$.

1. Marginal products

By the chain rule:

$$\begin{aligned}MP_1&=\frac1\alpha\left(z_1^\alpha+z_2^\alpha\right)^{1/\alpha-1}\cdot\alpha z_1^{\alpha-1}\\&=\boxed{\left(z_1^\alpha+z_2^\alpha\right)^{1/\alpha-1}z_1^{\alpha-1}.}\end{aligned}$$
$$\boxed{MP_2=\left(z_1^\alpha+z_2^\alpha\right)^{1/\alpha-1}z_2^{\alpha-1}.}$$

2. MRTS

$$\begin{aligned}MRTS_{12}&=\frac{MP_1}{MP_2}=\frac{z_1^{\alpha-1}}{z_2^{\alpha-1}}\\&=\left(\frac{z_1}{z_2}\right)^{\alpha-1}=\boxed{\left(\frac{z_2}{z_1}\right)^{1-\alpha}.}\end{aligned}$$
Key algebra. $\left(\frac{z_1}{z_2}\right)^{\alpha-1}=\left(\frac{z_2}{z_1}\right)^{1-\alpha}$ because $\left(\frac{z_1}{z_2}\right)^{-a}=\left(\frac{z_2}{z_1}\right)^a$. This uses the same ratio $z_2/z_1$ as the definition of $\sigma$.

3. Take logarithms

$$\ln MRTS_{12}=(1-\alpha)\ln\left(\frac{z_2}{z_1}\right).$$

We differentiate both sides with respect to $z_2/z_1$:

$$\frac{d\ln MRTS_{12}}{d(z_2/z_1)}=(1-\alpha)\frac{1}{z_2/z_1}. $$
$$\boxed{\frac{d\ln MRTS_{12}}{d(z_2/z_1)}=\frac{1-\alpha}{z_2/z_1}.}$$

Pass to differentials. Multiplying both sides by $d(z_2/z_1)$:

$$d\ln MRTS_{12}=\frac{1-\alpha}{z_2/z_1}d(z_2/z_1).$$

Using $d\ln(x)=\frac1x dx$, we obtain:

$$\boxed{d\ln MRTS_{12}=(1-\alpha)d\ln\left(\frac{z_2}{z_1}\right).}$$

Equivalently:

$$d\ln\left(\frac{z_2}{z_1}\right)=\frac1{1-\alpha}d\ln MRTS_{12}. $$

4. Elasticity of substitution

$$\sigma=\frac{d\ln(z_2/z_1)}{d\ln MRTS_{12}}=\boxed{\frac1{1-\alpha}.}$$

Since $\alpha<1$, the elasticity is positive and constant across input bundles.

Interpretation

Along an isoquant, a 1% increase in MRTS is associated locally with a $\sigma\%$ increase in $z_2/z_1$. The parameter $\alpha$ determines how easily the inputs can replace each other:

ParameterElasticityInterpretation
$0<\alpha<1$$\sigma>1$Easier substitution than Cobb-Douglas; not perfect substitutes.
$\alpha<0$$0<\sigma<1$Harder substitution than Cobb-Douglas; not perfect complements.
$\alpha\to1^{-}$$\sigma\to+\infty$Perfect substitutes in the limit: linear isoquants and constant MRTS.
$\alpha\to-\infty$$\sigma\to0$Perfect complements in the limit: inputs used in fixed proportions (Leontief).
Conclusion for this exercise: for any finite $\alpha<1$, $\alpha\neq0$, substitution elasticity is finite and strictly positive. The inputs are therefore neither perfect substitutes nor perfect complements; those are limiting cases.
