4. Efficiency

From using inputs efficiently to minimizing cost and maximizing profit.

01 · Using the technology efficiently

Output and Technical Efficiency

These two concepts concern the quantities a technology can produce. Input prices are not needed to assess them.

Output efficiency · Given inputs

The firm cannot produce more output with the same inputs.

$$\boxed{y=f(z)}$$

The output produced reaches the maximum allowed by the technology.

Technical efficiency · Given output

The firm cannot produce the same output with less of at least one input and no more of any other input.

With several inputs, this means reducing inputs component by component, rather than adding their quantities together.

Read the two improvements

$E^1\to E^2$: output rises while input stays unchanged. Therefore, $E^1$ is output inefficient.

$E^3\to E^2$: input falls while output stays unchanged. Therefore, $E^3$ is technically inefficient.

These comparisons show why $E^1$ and $E^3$ are inefficient; they do not, by themselves, rule out every possible improvement on $E^2$.

Link with earlier chapters. Writing $y=f(z)$ assumes output efficiency. A merely feasible production plan only needs to satisfy $y\leq f(z)$.
When are output efficiency and technical efficiency equivalent?

For positive output, they coincide when $f$ is continuous, strictly increasing in each input, and satisfies $f(0)=0$.

Output efficiency implies technical efficiency. Starting from $y=f(z)$, reducing an input without increasing another strictly reduces maximum output. The original output can no longer be produced.

Technical efficiency implies output efficiency. If $y<f(z)$, continuity allows a small reduction in inputs while still producing $y$. This contradicts technical efficiency.

The assumptions matter: with a flat part of the production frontier, maximum output may still be achievable with fewer inputs.

02 · Choosing the least-cost inputs

Economic Efficiency

For a given output and given input prices, a firm is economically efficient when no feasible input combination costs less.

The link with cost minimization

Let $w$ be the vector of input prices and $z^*$ the firm's chosen inputs. Economic efficiency requires:

$$\boxed{w\cdot z^*=c(w,y)}\qquad c(w,y)=\min_{z\geq0}\{w\cdot z:f(z)\geq y\}.$$

The cost of the chosen bundle must equal the minimum cost of producing $y$.

Economic efficiency implies technical efficiency

Assume every input price is strictly positive. If an input could be reduced without increasing another or lowering output, cost would fall. The original bundle could not be cost-minimizing.

The converse does not hold

A technically efficient firm may still use an expensive input mix. It can sometimes reduce cost by using more of a cheaper input and less of an expensive input, while keeping output unchanged.

Physical efficiency is not enough. Technical efficiency rules out wasted inputs. Economic efficiency also requires the right input mix at the prevailing prices.

Cost minimization takes output as given. Profit maximization also chooses how much to produce.

03 · Efficiency and profit maximization

The Production Side of the Welfare Theorems

The two results connect efficient production plans with profit-maximizing choices. Read them in opposite directions, with different assumptions.

Read the notation before the results

Here $y\in Y$ denotes a net-output vector, rather than a single output quantity: outputs have positive components and inputs have negative components. With prices $p$, profit is $p\cdot y$.

A production plan is efficient if no other feasible plan improves at least one component without worsening another:

$$\nexists\,y'\in Y:\quad y'\geq y\quad\text{and}\quad y'\neq y.$$

Since inputs enter negatively, a larger component can mean more output or less input. This is a physical comparison of whole production plans; the previous section compared costs at a fixed output and given input prices.

First Welfare Theorem · From profit maximization to efficiency

If $y^*\in Y$ maximizes profit at strictly positive prices ($p\gg0$, meaning $p_i>0$ for every good), then $y^*$ is an efficient production plan.

Why? Any feasible improvement would raise revenue or reduce input cost, so it would increase profit.

Convexity of $Y$ is not required for this direction.

Show the proof by contradiction

1. Start from profit maximization. No feasible plan yields more profit than $y^*$:

$$p\cdot y^*\geq p\cdot y'\qquad\text{for every }y'\in Y.$$

2. Suppose $y^*$ is inefficient. There must be a feasible $y'$ with $y'\geq y^*$ and at least one strict inequality.

3. Value this improvement at prices $p$. All terms below are nonnegative, and at least one is strictly positive because every $p_i>0$:

$$p\cdot y'-p\cdot y^*=\sum_i p_i(y_i'-y_i^*)\gt0.$$

This contradicts step 1. Therefore, $y^*$ is efficient.

If a price were zero, improving only that component might leave profit unchanged. Strictly positive prices make the contradiction work.

Second Welfare Theorem · From efficiency to supporting prices

If $Y$ is convex and $y^*\in Y$ is efficient, there exists a nonzero, nonnegative price vector at which $y^*$ maximizes profit:

$$\boxed{p\geq0,\quad p\neq0}\qquad p\cdot y^*\geq p\cdot y'\quad\forall y'\in Y.$$

The result says some prices can support this plan. It does not say the plan maximizes profit at any given market prices; some supporting prices may be zero.

What does convexity contribute?

Convexity makes it possible to support the efficient plan with a price hyperplane: all feasible production plans lie on or below the profit level reached by $y^*$.

$$p\cdot(y'-y^*)\leq0\qquad\text{for every }y'\in Y.$$

This is exactly the profit-maximization condition. Without convexity, an efficient plan need not be profit-maximizing for any nonzero, nonnegative prices.

Profit maximization → efficiencyAll prices are strictly positive.A profitable improvement cannot have been left unused.
Efficiency → profit maximization at some pricesThe production set is convex.Supporting prices exist; they are nonnegative and not all zero.

These are the production-side results. Full welfare theorems also concern consumers and market equilibrium.
