5. Efficiency

Technical, economic, and welfare efficiency.

5 · Efficiency

Output and Technical Efficiency

Output efficiency

It is impossible to use the same input level to produce more output.

Technical efficiency

It is impossible to produce the same output level with fewer inputs.

Read the feasible points

$E^1$ is output inefficient: with the same input level, the firm can reach the output of $E^2$.

$E^3$ is technologically inefficient: it produces the same output as $E^2$ with more input.

Course note. It is often implicitly assumed that the firm is output efficient. The technological constraint is then written as binding: $y=f(z)$.

Relationship between the two concepts

$$\text{Technical efficiency}\Longleftrightarrow\text{Output efficiency}.$$

Technical efficiency implies output efficiency: if the firm uses the minimum inputs to produce a given output, it cannot use those same inputs to produce more.

Output efficiency implies technical efficiency: under monotonic production, if the firm produces the maximum output for given inputs, it cannot produce the same output with fewer inputs.

Economic Efficiency

Economic efficiency is achieved when it is impossible to produce the same output level at a lower cost. It differs from technical efficiency and output efficiency.

$$\text{Economic efficiency}\Longrightarrow\text{Technical efficiency} \Longleftrightarrow\text{Output efficiency}.$$

Why economic efficiency implies technical efficiency

If it is impossible to reduce cost, it is impossible to decrease the quantity of at least one input, because decreasing an input is the way to reduce cost. Thus it is impossible to decrease the total quantity of inputs.

Why technical efficiency need not imply economic efficiency

Technical efficiency prevents a reduction in the total quantity of inputs. It does not prevent changing the input ratio to reduce costs. A lower-cost combination can therefore still be possible.

Economic Efficiency and Welfare

Production side of the First Welfare Theorem

If a production vector $y\in Y$ is profit-maximizing for some price vector $p\gg0$, then it is economically efficient.

Proof. Suppose that $y$ is profit-maximizing:

$$p\cdot y\geq p\cdot y' \qquad\text{for all }y'\in Y.$$

Suppose by contradiction that $y$ is not efficient. Then there is $y'\in Y$ with $y'\geq y$ and $y'\neq y$. Since $p\gg0$, it follows that:

$$p\cdot y'>p\cdot y.$$

But this contradicts the profit-maximizing property of $y$.

Production side of the Second Welfare Theorem
